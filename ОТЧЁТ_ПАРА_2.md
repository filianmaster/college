# Практическая работа №2 — День 5

**Проект:** StudyFlow — IT Study Planner

**Цель:** разработать веб-приложение для планирования учебных задач, проверить основные функции и подготовить проект к публикации.

## Реализованные функции
1. Добавление задач.
2. Редактирование и удаление задач.
3. Изменение статуса выполнения.
4. Поиск, фильтрация и сортировка.
5. Сохранение после перезагрузки.
6. Проверка обязательных полей.
7. Адаптивный интерфейс.

## Проверка
Проверены открытие сайта, добавление, изменение, удаление и завершение задачи, сохранение данных после перезагрузки, пустая форма и отображение на мобильном экране.

## Результат
Создан работающий прототип учебного планировщика, готовый к локальному запуску и публикации через GitHub Pages.

**Примечание:** текущая версия использует localStorage, а не облачное хранилище Firebase.
