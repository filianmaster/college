# IT Study Planner

IT Study Planner — простое веб-приложение для планирования учебных задач. Оно помогает записывать дела, отслеживать выполнение и фильтровать список.

## Используемые технологии

- HTML5 — структура страницы.
- CSS3 — оформление и адаптация под мобильные устройства.
- JavaScript — логика приложения и обработка действий пользователя.
- localStorage — сохранение задач в браузере.

## Возможности

- Добавление новых задач.
- Удаление задач.
- Отметка задач как выполненных.
- Фильтрация: все, активные и выполненные.
- Отображение количества задач и статистики.
- Автоматическое сохранение данных в localStorage.

## Запуск

1. Скачайте или клонируйте репозиторий.
2. Откройте файл `index.html` в браузере.
3. Добавляйте задачи и отмечайте их выполнение.

## Структура проекта

- `index.html` — разметка приложения.
- `style.css` — стили и адаптивный дизайн.
- `script.js` — логика работы приложения.
- `README.md` — описание проекта.
