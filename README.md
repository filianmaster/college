# StudyFlow — IT Study Planner (День 5, пара 2)

## Запуск
Распакуйте архив и откройте `index.html` в Chrome или Edge.

## Возможности
- Добавление, редактирование и удаление задач.
- Отметка выполнения.
- Поиск и фильтрация: все, сегодня, в процессе, выполненные.
- Сортировка по сроку, приоритету и названию.
- Проверка обязательных полей.
- Статистика и прогресс.
- Адаптивный интерфейс и тёмная тема.
- Автосохранение в localStorage браузера.

## Тест-кейсы
1. Открыть сайт — страница загружается.
2. Добавить задачу — она появляется в списке.
3. Перезагрузить страницу — задача сохраняется.
4. Изменить задачу — изменения отображаются.
5. Отметить выполненной — статус и статистика меняются.
6. Удалить задачу — она исчезает.
7. Отправить пустую форму — браузер не позволяет сохранить пустое название/дату.
8. Открыть на телефоне — интерфейс адаптируется.

Негативные тесты: пустое название; пустая дата; поиск несуществующей задачи.

## Публикация на GitHub Pages
Загрузите файлы проекта в репозиторий GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Важно про Firebase
Эта готовая версия хранит данные локально в браузере, а не в Firebase. Для настоящего облачного хранения нужно отдельно подключить Firebase Authentication и Firestore, указать конфигурацию своего проекта и проверить Security Rules. Поэтому не представляйте localStorage как облачную базу.

## Структура
- `index.html` — разметка
- `style.css` — оформление
- `script.js` — логика приложения
- `firestore.rules` — пример правила для будущего подключения Firestore
