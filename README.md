# IT Study Planner AI

Учебный проект — планировщик задач студента на HTML, CSS и JavaScript.

## Возможности

- Добавление и удаление учебных задач.
- Категории: HTML, CSS, JavaScript, Python и Другое.
- Статусы: все, активные и выполненные.
- Приоритеты: высокий, средний и низкий.
- Сортировка по приоритету, дате и названию.
- Индикатор выполнения и статистика.
- Сохранение данных в `localStorage`.
- Экспорт списка задач в CSV.
- Адаптивный интерфейс для компьютера и смартфона.

## Структура проекта

- `index.html` — структура страницы.
- `style.css` — оформление и адаптивная вёрстка.
- `script.js` — логика приложения.
- `README.md` — описание проекта.

## Запуск

Откройте `index.html` в браузере. Для публикации загрузите все файлы в корень GitHub-репозитория.

## Проверка

1. Добавьте задачу без названия — приложение должно показать предупреждение.
2. Добавьте несколько задач с разными категориями и приоритетами.
3. Отфильтруйте задачи по статусу и категории.
4. Переключите сортировку и проверьте порядок.
5. Отметьте задачу выполненной — должны обновиться статистика и прогресс.
6. Обновите страницу — задачи должны остаться.
7. Нажмите «Экспорт CSV» — должен скачаться файл со списком.
8. Очистите список и подтвердите действие.

## Технологии

HTML5, CSS3, JavaScript (DOM, события, массивы, объекты, localStorage, Blob API).
